# ⚡ CUDA Programming & Parallel Computing Journey

Welcome to my CUDA programming learning repository! This project serves as a structured documentation of my hands-on experience, code snippets, parallel algorithms, and performance optimizations using **NVIDIA CUDA C/C++**.

---

## 📌 Objectives

- Master the fundamentals of GPU architecture (Grids, Blocks, Threads, Warps, Memory Hierarchy).
- Implement foundational parallel computing primitives (Prefix Sum, Histogram, Matrix Multiplication, Convolution).
- Practice memory optimization techniques (Shared Memory, Coalesced Access, Bank Conflicts avoidance).
- Explore parallel file compression techniques and GPU-accelerated algorithms.
